# Reference image specification

## Image 1 — teacher workspace

The supplied teacher dashboard is a light, high-density workspace with a narrow white navigation rail on the left and a warm-white content canvas. The visual language uses rounded 6–12px cards, thin cool-grey borders, very soft shadows, compact sans-serif labels, and saturated blue, teal, magenta and ochre status colors. The primary content is a timeline, a weekly/monthly timetable, subject tiles, quick actions and announcement cards.

## Image 2 — HR and payroll

The supplied HR reference uses a pale blue-grey canvas, large white content panels, blue section headings, pink outlined actions, pale mint approval chips and clear payroll line items. The implementation reuses these relationships in the HR & Payroll route and keeps actions compact and high contrast.

## Fidelity decisions

- Sidebar and top bar use the same low-contrast white shell in both references.
- KPI, timetable, approval and form surfaces use thin grey borders rather than heavy shadows.
- Blue is the primary action color; teal signals positive/approved; ochre signals review; pink signals exceptions.
- Demo content replaces sample values while preserving the composition and density.
- No production claims are made: the visible DEMO MODE marker distinguishes synthetic records.
