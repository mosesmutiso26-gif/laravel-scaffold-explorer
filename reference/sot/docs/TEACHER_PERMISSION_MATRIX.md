# Teacher Permission Matrix

| Capability | Teacher | Notes |
|---|---:|---|
| View assigned timetable/classes/students | Yes | Scope limited to assigned class and subject relationships |
| Take and submit attendance | Yes | Only valid assigned sessions; correction may require approval |
| Create lesson plans, schemes, resources | Yes | Draft and submit within assigned scope |
| Create/publish assignments | Yes | Published content should be versioned by Laravel |
| Mark submissions and enter marks | Yes | Maximum marks and grading rules are server-defined |
| Moderate/publish final reports | No by default | Read or respond only when granted by school policy |
| View finance, payroll, HR or medical data | No | Not present in teacher navigation |
| Message minors privately | No | Communication must follow school policy and approved recipients |
| Submit own leave | Yes | Cannot approve own request |
| Change own permitted profile/preferences | Yes | Payroll and HR-only fields excluded |
