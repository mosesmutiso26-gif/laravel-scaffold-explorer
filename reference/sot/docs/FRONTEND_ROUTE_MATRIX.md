# Frontend route matrix

| Route | Surface | Status | Demo source |
|---|---|---|---|
| `/` | Public homepage | Frontend implemented | Existing school content |
| `/about`, `/leadership`, `/teachers`, `/academics`, `/admissions`, `/facilities`, `/news`, `/contact`, `/careers` | Public website pages | Frontend implemented | Existing school content |
| `/erp` | Role-based ERP workspace | Demo workflow implemented | Shared synthetic repository in the page |
| `/admin` | Administrator entry to the same role-aware workspace | Demo workflow implemented | Same synthetic repository; permissions remain a backend contract |

ERP sections are selected from the shared navigation: Overview, Students, Academics, Attendance, Finance, HR & Payroll, Website CMS and Reports.
